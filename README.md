# Still Polarized - Wiki

Interlinked Markdown knowledge base for the Still Polarized corp wiki.

## Open it
- **Obsidian (easiest):** Obsidian -> Open folder as vault -> select this folder. Wikilinks and the graph view work out of the box.
- **GitHub (team):** `git init` in this folder, add a remote, push. Everyone clones. GitHub's web view renders the markdown (wikilinks display as plain text in web view).
- **Notion (later):** import the folder; links become page references.

## Conventions
- One file per page; the page name is the file name (without extension).
- Link pages with [[Page-Name]].
- New page: copy a file from `templates/`, rename it (drop the `Tpl-` prefix), fill it in, and link it from the relevant index page.
- Undecided items are marked `TBC`. Search `TBC` across the vault to find every open item.
- English only.
